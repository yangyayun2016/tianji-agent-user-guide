# 报告与定时任务

分析做完了，怎么把它变成能发出去的东西、怎么让它每天自动跑一遍——这一页讲这两件事。

---

## 一、生成报告

### 怎么生成

每轮回答完成后，回答下方会出现「**生成报告分析**」按钮。点一下，稍等片刻（复杂分析可能要一两分钟），就会得到一份排版好的 HTML 分析报告。

报告是**手动触发**的，不会每次回答都自动生成——避免随手问一句也占用积分和时间。

### 报告长什么样

不是把对话原样导出，而是重新组织成一份仪表盘式的分析文档：结论前置、数据以图表和表格呈现、分节排版。可以直接发给同事或客户看。

### 生成用哪个模型

跟你当前对话所用的模型一致。想要报告质量更好，在生成前把对话模型切到 Claude Opus 4.8 再点按钮。

### 报告能做什么

| 操作 | 说明 |
|---|---|
| 查看 | 在页面内直接打开 |
| 下载 | 存成 HTML 文件到本地 |
| 分享 | 复制公开链接，对方不用登录就能打开 |

> 分享链接是公开的，拿到链接的人都能看。含店铺敏感数据的报告请谨慎外发。

### 对话文档面板

对话页顶部的「**对话文档**」面板汇总了当前这段对话生成过的全部报告，点开可直接跳转，不用往上翻聊天记录找。

### 报告生成失败或卡住

- 稍等：复杂分析生成时间较长，页面会自动轮询等待结果
- 重试：等待超时后重新点一次按钮
- 换模型：某些模型在长文本生成上更稳，切到 Claude Opus 4.8 再试

---

## 二、导出表格

助手取回的数据如果是表格形态，工具结果卡片上会出现导出按钮，一键存成 Excel 文件，可以直接拿去做二次加工。

## 三、定时任务

把一段分析设成定时任务，到点自动跑，不用你每天手动问一遍。

### 创建任务

左侧「定时任务」→ 右上角新建，填这几项：

| 字段 | 说明 |
|---|---|
| **任务名称** | 例如「每日销售报告」 |
| **任务内容** | 用大白话描述你希望助手做什么，写法跟平时提问一样 |
| **执行频率** | 每小时 / 每天 / 每周 / 每月 |
| **执行时间** | 具体到几点（每小时频率时无需填） |
| **执行星期** | 仅「每周」需要，选周一到周日 |
| **每月第几日** | 仅「每月」需要 |
| **使用模型** | 可选，不填则用系统默认 |

时间按**北京时间**执行。

### 任务内容怎么写

跟在对话框里提问一样，写清楚要什么。比如：

```
生成昨日所有店铺的销售数据汇总报告，包括销售额、订单量、退货率，
并指出环比变化超过 20% 的异常项
```

```
查一下我们主推的 5 个 ASIN 昨天的广告花费和 ACoS，
有超过 40% 的单独标出来
```

**任务里要用到的连接器、知识库或数据库，必须提前配好。** 定时任务跑的时候没有人在旁边帮它填密钥。

### 管理任务

任务列表里每条任务可以：

- **立即执行一次** — 不等到点，马上跑一遍，用来验证任务写得对不对
- **启用 / 停用** — 暂时不想跑就停用，配置保留
- **编辑** — 改内容、改频率、改模型
- **删除** — 彻底移除

### 查看执行记录

每条任务都有执行记录，显示每次运行的状态：

| 状态 | 含义 |
|---|---|
| 运行中 | 正在执行 |
| 成功 | 执行完成，可查看产出 |
| 失败 | 执行出错，记录里有失败原因 |

点开某次记录能看到那次运行的完整结果。

### 定时任务同样扣积分

每次自动执行都按所用模型扣积分。设成「每小时」的任务，一天会跑 24 次——建议先用「立即执行一次」确认任务有效，再决定频率。**余额不足时任务会执行失败**，记得留意余额。

### 建议

**新建任务先手动跑一次。** 用「立即执行一次」验证，别等第二天早上才发现任务写得不对。

**频率别设太高。** 大多数日报周报，「每天」就够了。

**执行结果在任务详情里看。** 任务跑完的产出保存在该任务的执行记录中，登录后到「定时任务」页展开对应记录即可查看。
