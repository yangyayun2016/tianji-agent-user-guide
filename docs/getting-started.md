# 快速开始

跟着这一页走完，你会完成注册、配好第一个数据源，并问出第一个带真实数据的问题。全程约 10 分钟。

![用户使用流程：注册 → 配置连接器 → @ 连接器提问 → 看它取数分析 → 一键生成报告](./images/user-flow.svg)

## 第 1 步：注册账号

打开天机智能体网址，进入登录页，切换到「注册」。

| 字段 | 规则 |
|---|---|
| 用户名 | 4–20 位，须以字母开头，只能含字母、数字、下划线 |
| 密码 | 不少于 6 位 |
| 邀请码 | 选填。填了对方的邀请码，你额外得 20 积分，邀请人得 50 积分 |

注册成功即**赠送 100 积分**，可以直接开始对话。

> 如果你是从别人发来的邀请链接进来的（形如 `.../login?invite=XXXXXXXX`），邀请码会自动填好，页面也会自动切到注册模式。

> 老用户注意：早期版本只用用户名登录、没有密码。这类账号首次登录后会被要求补设一个密码，设完才能继续用。

## 第 2 步：认识主界面

登录后进入「智能对话」页。界面分三块：

- **左侧导航** — 智能对话、定时任务、技能市场、连接器、渠道、资产库、知识库、项目
- **中间对话区** — 提问和查看回答的地方
- **右上角头像** — 个人资料、积分中心、退出登录

对话输入框的下方会显示当前所选模型的单价和你的实时积分余额。

## 第 3 步：选一个模型

对话框上方有模型下拉框。可选的模型取决于本站开通了哪几家，常见的是这几个：

| 模型 | 特点 | 每次对话 |
|---|---|---|
| DeepSeek V4 Flash | 快、便宜，日常问答够用 | 1 积分 |
| DeepSeek V4 Pro | 更强，会展示思考过程 | 2 积分 |
| GPT-OSS 120B | 会展示思考过程 | 2 积分 |
| Claude Opus 4.8 | 最强，支持看图，复杂分析首选 | 5 积分 |

刚上手建议先用 DeepSeek V4 Flash 试水，等要做正经分析时再切到更强的模型。

> 下拉框里没看到某个模型，说明本站没有开通那家的服务，不是你的账号问题。

## 第 4 步：配置第一个连接器

不配连接器也能聊天，但那样助手只能凭通用知识回答。要让它取真实数据，至少配一个。

1. 左侧点「连接器」
2. 挑一个你已经有账号的平台（比如「FlyFus API」或「领星 ERP」），点「配置」
3. 按提示填 Key / Secret（每个平台去哪拿密钥，见[连接器](./connectors.md)）
4. 点「验证连接」，看到成功提示后点「保存」

各连接器需要填什么，速查：

| 连接器 | 需要填 |
|---|---|
| SIF 广告透视仪 | Secret Key |
| 卖家精灵 | Secret Key |
| Sorftime | Account SK |
| FlyFus MCP | API Key |
| SIF 坑位监控 | API Key |
| 领星 ERP | App ID + App Secret |
| FlyFus API | API Key |

## 第 5 步：问出第一个问题

回到「智能对话」，在输入框里 `@` 一下刚配好的连接器，然后用大白话提问：

```
@FlyFus API 帮我查一下 B0C8M8JVMC 这个商品的详细信息
```

回车之后你会看到：

1. 助手先显示「正在调用工具」的折叠卡片，写明它调了哪个数据源
2. 卡片展开能看到取回来的原始数据
3. 然后是基于这些数据写出来的分析结论

如果你选的模型支持思考过程，正文之前还会有一段可展开的「思考中…」区块，写明它打算怎么查。

## 第 6 步（可选）：生成一份报告

每轮回答结束后，下方会出现「生成报告分析」按钮。点它，稍等片刻就会得到一份排版好的 HTML 分析报告，可以直接看、可以下载，也可以复制公开链接发给同事。
