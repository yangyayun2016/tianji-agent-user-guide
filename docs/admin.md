# 管理后台

> 本页面向**站点管理员**。普通用户用不到，可以跳过。

管理后台用于管理会员、调整积分、发布公告、查看用量。

## 访问

在天机站点地址后加 `/admin`：

```
https://你的天机站点/admin
```

后台是独立的账号密码登录，**跟前台用户账号不通用**。

> **首次部署后，请立即修改默认管理员密码。** 默认账号仅用于首次登录，不改会带来明显的安全风险。登录后在后台修改密码。

## 功能

### 仪表盘

站点整体概览：用户总量、对话量、积分消耗等关键指标。

### 会员管理

- 查看全部注册用户：用户名、注册时间、最近登录、当前积分余额
- 查看单个用户详情，包括其积分明细与使用情况
- **调整积分** — 给指定用户增加或扣减积分，变动会写入流水，标记为管理员调整
- **重置登录密码** — 用户忘记密码时由管理员代为重置

### 流水总账

全站积分流水，可按用户、类型、时间查询。每笔记录含类型（注册赠送 / 对话消耗 / 邀请奖励 / 管理员调整）、金额、变动后余额、对应模型与会话。

### Token 监控

- **总览** — 全站 Token 用量统计，按模型、按时间维度汇总
- **明细** — 逐条用量记录，可下钻到具体用户和会话

对话和报告生成的用量都会记录在这里，用于核算实际成本。

### 公告管理

发布站内公告。**同一时间只有一条公告生效**，发布新公告会替换旧的。公告会显示在前台顶部横幅，所有登录用户可见。

适合用来通知维护窗口、新功能上线、连接器变更。

### 系统参数

调整全站生效的运行参数，例如单段对话的上下文轮数上限（默认 20 轮）。

## 安全注意事项

1. **首次登录立即改密码。** 这是最重要的一条。
2. **后台地址不要外传。** 虽然有密码保护，但少一个已知入口就少一分风险。
3. **积分调整会留痕。** 每笔管理员调整都写入流水，可追溯到操作结果。
4. **重置用户密码前先核实身份。** 避免被冒充的求助骗过去。
