## 为什么需要天机

做跨境的人都熟悉这个流程：选品要开卖家精灵和 Sorftime，看广告要开 SIF，查订单库存要登领星 ERP，研究关键词又得回到 ABA 数据。每个平台都有自己的账号、自己的导出按钮、自己的表格格式。真正花时间的不是分析，是把数据从各处捞出来、拼到一起。

更麻烦的是，这些数据单看都没用。「广告花了钱但没出单」这个问题，要同时看广告结构、关键词坑位、真实订单，才能回答——而这三份数据分别躺在三个平台里。

天机做的事很简单：**把这些数据源统一接进一个对话框。** 你问问题，它自己判断该调哪个平台的哪个数据、取哪段时间的数，然后给出带数据依据的结论。你不需要知道背后取了什么，只需要会提问。

## 能干什么

| 场景 | 一句话说明 |
|---|---|
| **选品调研** | 一个品类值不值得做，市场多大、集中度如何、新品还有没有空间 |
| **广告诊断** | 广告结构长什么样，钱花在哪、哪个 Campaign 在拖后腿 |
| **关键词研究** | ABA 搜索量趋势、点击转化集中度、坑位实时排名 |
| **竞品分析** | 竞品的价格 / BSR / 评论历史曲线，买家在评论里抱怨什么 |
| **店铺数据问答** | 订单、库存、销售报表，用自然语言查 |
| **知识库问答** | 上传自己的运营 SOP、产品资料，让助手基于自有资料回答 |
| **定时报告** | 每天早上自动跑一遍分析，结果推到飞书 |

## 能接哪些数据源

| 连接器 | 主要用途 |
|---|---|
| SIF 广告透视仪 | 广告结构与流量分析 |
| 卖家精灵 | 关键词研究与竞品分析 |
| Sorftime | 选品分析与市场趋势 |
| FlyFus MCP | 商品 / 关键词 / 市场三大数据引擎 |
| SIF 坑位监控 | 关键词坑位实时快照 |
| 领星 ERP | 订单、库存、销售报表 |
| FlyFus API | 商品详情、关键词分析、类目数据 |

配好密钥就能用，一个平台配一次，以后一直有效。详见 [连接器](./connectors.md)。

## 三步就能上手

![用户使用流程：注册 → 配置连接器 → @ 连接器提问 → 看它取数分析 → 一键生成报告](./images/user-flow.svg)

1. **配一次密钥** —— 在「连接器」页把你已有的平台账号密钥填进去
2. **提问** —— 在对话框里 `@` 选中连接器，用大白话问
3. **看结论** —— 助手先展示取到了什么，再给出分析；需要的话一键生成报告

全程约 10 分钟，跟着 [快速开始](./getting-started.md) 走一遍就会了。
