# 飞书接入

把天机接进飞书，就能在飞书里 @ 机器人直接提问，不用打开网页。

## 先看清能力边界

飞书里的机器人是一个**轻量问答入口**，跟网页端不是一回事：

| | 网页端 | 飞书 |
|---|---|---|
| 连接器取数 | ✅ | ❌ |
| 知识库 / 数据库 | ✅ | ❌ |
| 技能（四位分析师） | ✅ | ❌ |
| 多轮上下文 | ✅ | ❌ 每条独立 |
| 选模型 | ✅ | ❌ 用系统默认 |
| 看工具调用过程 | ✅ | ❌ |
| 生成报告 | ✅ | ❌ |
| 图片 / 文件消息 | ✅ | ❌ 会被忽略 |

所以飞书适合的是随口一问：概念解释、写个 Listing 文案、快速请教。**凡是要查真实数据的问题，请回网页端。**

## 配置步骤

### 第 1 步：在天机侧连接

1. 左侧点「渠道」
2. 找到「飞书」卡片，点进去
3. 填入 **App ID**（形如 `cli_xxx`）和 **App Secret**
4. 点连接

连接成功后，页面上会显示一条 **Webhook URL**，形如：

```
https://你的天机站点/api/webhook/feishu/xxxxxxxx……
```

**把这条 URL 复制下来**，下一步要用。

### 第 2 步：在飞书开放平台配置

App ID 和 App Secret 从[飞书开放平台](https://open.feishu.cn)拿：

1. 进入开发者后台 → 创建企业自建应用
2. 在「凭证与基础信息」里拿到 App ID 和 App Secret，填回天机
3. 在「事件订阅」里，把上一步复制的 Webhook URL 填为请求地址
   - 飞书会立即发一个校验请求，天机自动响应，显示校验通过即可
4. 订阅**接收消息**相关事件
5. 在「权限管理」里开通机器人接收消息、发送消息所需的权限
6. 发布应用版本，等企业管理员审核通过
7. 在飞书里把机器人加进群，或直接跟它单聊

### 第 3 步：试一下

在群里 @ 机器人：

```
@天机 帮我写一段无线充电器的五点描述
```

机器人会在飞书里回复。@ 提及本身会被自动去掉，不影响它理解你的问题。

## 常见问题

**@ 了没反应？**
按顺序排查：应用版本是否已发布并通过审核 → 事件订阅的请求地址是否填对且校验通过 → 权限是否开全 → 天机「渠道」页里飞书状态是否为已连接。

**问它「我的销量多少」，它答不上来？**
这是预期行为。飞书入口不接连接器和数据库，查数据请回网页端。

**回复很慢？**
飞书是等完整答案生成完再一次性回复，没有网页端的逐字输出，所以感觉更慢。

**发图片没反应？**
目前只处理文字消息。

**回复「AI 响应失败」？**
模型服务临时异常或响应超时，稍后重试；持续出现请联系管理员。

**怎么断开？**
在「渠道」页断开即可，配置保留，重新连接不用重填。

## 安全提示

Webhook URL 等同于你账号在飞书侧的入口，**不要贴到公开文档、群公告或代码仓库里**。注意：断开再重新连接**不会**更换这条 URL；如果确认已泄露，请联系管理员处理。
