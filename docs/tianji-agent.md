# 天机智能体：跨境电商的 AI 数据分析助手

## 定位

一个懂跨境电商的 AI 助手。把你已经在用的选品、广告、关键词、ERP 数据源接进来，用一句话提问，它自己去取数、分析、出结论。

## 愿景

让跨境卖家不再在七八个后台之间来回切换、导表、对数。选品、投放、运营的判断，都能在一个对话框里问出来。

## 为什么需要天机

做跨境的人都熟悉这个流程：选品要开卖家精灵和 Sorftime，看广告要开 SIF，查订单库存要登领星 ERP，研究关键词又得回到 ABA 数据。每个平台都有自己的账号、自己的导出按钮、自己的表格格式。真正花时间的不是分析，是把数据从各处捞出来、拼到一起。

更麻烦的是，这些数据单看都没用。「广告花了钱但没出单」这个问题，要同时看广告结构、关键词坑位、真实订单，才能回答。而这三份数据分别躺在三个平台里。

天机做的事很简单：把这些数据源统一接进一个对话框。你问问题，它自己判断该调哪个平台的哪个接口、取哪段时间的数，然后给出带数据依据的结论。你不需要知道背后调了什么，只需要会提问。

## 能干什么

- **选品调研** — 一个品类值不值得做，市场多大、集中度如何、新品还有没有空间
- **广告诊断** — 广告结构长什么样，钱花在哪、哪个 Campaign 在拖后腿
- **关键词研究** — ABA 搜索量趋势、点击转化集中度、坑位实时排名
- **竞品分析** — 竞品的价格/BSR/评论历史曲线，买家在评论里抱怨什么
- **店铺数据问答** — 订单、库存、销售报表，用自然语言查
- **知识库问答** — 上传自己的运营 SOP、产品资料，让助手基于自有资料回答
- **定时报告** — 每天早上自动跑一遍分析，结果推到飞书

## 核心特性

- 🔌 **接入你已有的数据源** — SIF、卖家精灵、Sorftime、FlyFus、领星 ERP，配好密钥就能用，不用重新买数据
- 🧠 **四位内置分析师** — 选品分析师、广告分析师、数据分析师、关键词研究员，各带一套专业分析框架
- 💬 **一句话取数** — 不用选工具、不用填表单，直接说人话，助手自己决定调什么
- 👀 **过程可见** — 每次调用了哪个数据源、取到什么，都在对话里以卡片展示，结论有据可查
- 🔁 **断了不丢** — 刷新页面、切走再回来，正在生成的回答会接着往下写，不用重问
- 📊 **一键出报告** — 任何一轮分析都能生成排版好的 HTML 报告，可下载、可分享链接
- 📁 **接自己的知识库和数据库** — 上传运营资料做检索，或直接连自己的业务库做数据问答
- ⏰ **定时跑** — 日报周报设成定时任务，到点自动跑、自动推送
- 🎚️ **模型自选** — 快的省积分、强的更准，每次对话自己挑

## 连接器矩阵

| 连接器 | 类型 | 主要用途 |
|---|---|---|
| SIF 广告透视仪 | MCP | 广告结构与流量分析 |
| 卖家精灵 | MCP | 关键词研究与竞品分析 |
| Sorftime | MCP | 选品分析与市场趋势 |
| FlyFus MCP | MCP | 商品 / 关键词 / 市场三大数据引擎 |
| SIF 坑位监控 | REST | 关键词坑位实时快照 |
| 领星 ERP | REST | 订单、库存、销售报表 |
| FlyFus API | REST | 商品详情、关键词分析、类目数据 |
