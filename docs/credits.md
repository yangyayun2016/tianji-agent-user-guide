# 积分与邀请

天机用积分计费。每次对话按所选模型扣一次积分，模型越强单价越高。

## 怎么获得积分

| 场景 | 积分 |
|---|---|
| 新用户注册 | +100 |
| 用别人的邀请码注册（你得） | +20 |
| 成功邀请一位好友注册（你得） | +50 |
| 管理员调整 | 视情况 |

## 怎么消耗积分

**每次对话按所选模型扣一次**，跟回答长短、调用了几次工具无关。

| 模型 | 每次对话 |
|---|---|
| DeepSeek V4 Flash | 1 积分 |
| DeepSeek V4 Pro | 2 积分 |
| GPT-OSS 120B | 2 积分 |
| Claude Opus 4.8 | 5 积分 |

几条规则值得知道：

- **回答正常完成才扣。** 中途出错或你主动中断，不扣积分。
- **余额不足会被拦下。** 余额低于本次所需时，直接提示积分不足，不会调用模型，也不产生流水。
- **数据库写入确认不扣积分。** 你点确认执行 SQL 的那一步不调用模型，不计费。
- **定时任务同样扣积分。** 每次自动执行按其所用模型扣费，频率设高了消耗会很快。

> 对话输入框下方一直显示当前模型的单价和你的实时余额，扣费后会立即刷新。

## 积分中心

右上角头像 →「积分中心」，可以看到：

- **余额总览** — 当前余额、累计获得、累计消耗、本月消耗、对话次数
- **模型单价卡** — 各档模型的单价，以及你分别用了多少次
- **邀请区** — 你的邀请码、一键复制邀请链接、已邀请好友列表及各自带来的收益
- **积分流水** — 每一笔变动的时间、类型、金额、变动后余额；可按「全部 / 获得 / 消耗」筛选，向下加载更多

对话产生的流水会记录当时用的是哪个模型、属于哪段会话，便于回溯。

## 邀请好友

1. 进「积分中心」，找到邀请区
2. 点复制，拿到你的专属邀请链接（形如 `.../login?invite=XXXXXXXX`）
3. 发给朋友。对方打开链接会自动进入注册模式并填好邀请码
4. 对方注册成功后，**你 +50，对方 +20**

每人有一个固定的 8 位邀请码，不会变。已邀请的好友和累计收益都能在邀请区看到。

> 早期注册的老用户如果还没有邀请码，第一次打开积分中心时会自动补发。

## 个人资料

右上角头像 →「个人资料」，可以看到和修改：

- **用户名** — 支持行内编辑，回车保存、Esc 取消。重名会被拒绝
- **注册时间 / 最近登录时间**
- **邀请人** — 谁邀请你来的
- **使用统计** — 对话次数、会话数、累计消耗、累计获得、已邀请人数

## 省积分的用法

**分级用模型。** 查个数、看个趋势，DeepSeek V4 Flash 完全够用（1 积分）。要它做判断、写分析、出报告时再切 Claude Opus 4.8（5 积分）。

**一次问全。** 信息给全，一轮就能取到数；给一半让它反问，一来一回就是两次扣费。

**定时任务频率别设太高。** 「每小时」意味着一天 24 次扣费。日报周报用「每天」就够。

**新任务先手动跑一次验证。** 比设成定时后每天失败要省。
