## 执行顺序说明

01–05 是准备阶段（理解素材、生成工程文件、画图），06 建仓，07–09 搭站点，10–11 发布上线，12–13 收尾。

第 07 步的 `base: '/tianji-agent-user-guide/'` 和第 11 步的 Source 选 **GitHub Actions**（不是 Deploy from a branch）是两个最容易漏掉、漏掉就上不了线的点。
