# 数据库连接

除了第三方平台，天机还能连你自己的业务数据库。连上之后，就可以用大白话查自家的数据，不用写 SQL。

配合[数据分析师](./skills.md)技能使用效果最好。

## 支持的数据库

目前支持 **MySQL**。

## 添加数据库连接

在「连接器」页面找到数据库连接入口，点添加，填以下信息：

| 字段 | 说明 |
|---|---|
| 连接名称 | 你自己看的名字，例如「订单库」「测试库」 |
| 主机地址 | 数据库服务器地址 |
| 端口 | 默认 3306 |
| 数据库名 | 要连的库名 |
| 用户名 | 数据库账号 |
| 密码 | 数据库密码 |

填完点「测试连接」，通过后保存。

### 连不上的常见原因

- **服务器没放行**：数据库所在服务器的防火墙 / 安全组要允许外部访问对应端口
- **账号没有远程权限**：MySQL 账号如果限定了 `localhost`，从外部连不上，需要授权对应来源
- **账号密码错误**：注意复制时不要带空格
- **库名写错**：填的是数据库名，不是表名

## 在对话中使用

`@` 选中你的数据库连接，然后直接提问：

```
@订单库 帮我看看这个月各店铺的销售分布
@订单库 退货率最高的 10 个 SKU 是哪些
@订单库 这张表里有哪些字段
```

助手会先摸清表结构（有哪些表、每张表有什么字段），再写 SQL 查询，最后把结果整理成表格或要点，并附上业务解读。

工具调用卡片里能看到它实际执行的 SQL——SQL 对不对，展开看一眼就知道。

## 安全设计

这部分需要你了解，因为涉及你自己的生产数据。

### 默认只读

助手自动执行的查询被限制为 **SELECT / SHOW / DESCRIBE / EXPLAIN** 四类。任何 `UPDATE`、`DELETE`、`DROP` 都不可能被它自动执行。

### 写操作必须你点确认

确实需要写数据时（比如让它把分析结果建张表存下来），助手不会直接执行。它会把打算执行的 SQL 完整列出来，等你在界面上看过并点确认之后才真正执行。**你不点，什么都不会发生。**

### 单次查询有上限

- 单次查询最多返回 **200 行**
- 查询超过 **30 秒**会被自动中止，避免一条没走索引的语句把你的库拖垮

### 建议：给它一个只读账号

最稳妥的做法是**专门建一个只读的数据库账号**给天机用，只授予你希望它能看到的那几张表的 SELECT 权限。这样即使出任何意外，也不可能影响到生产数据。

## 使用建议

**先让它认识你的库。** 第一次连上时，先问「这个库里有哪些表」「订单表有哪些字段」，让它把表结构摸清楚，后面的查询会准得多。

**字段名给提示。** 你的表结构它一开始并不了解。说「按 shop_name 分组」比说「按店铺分组」更容易一次对。

**大表加时间范围。** 「查所有订单」和「查上个月的订单」，在一张千万行的表上是两回事。

**结果不对就看 SQL。** 展开工具卡片，看它写的 SQL 是不是理解错了你的意思，然后补一句说明纠正它。
