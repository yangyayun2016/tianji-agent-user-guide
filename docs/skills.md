# 技能

技能是助手的「专业人格」。不开技能时，助手是一个通用的跨境电商助理；开了技能，它会切换到某个岗位的分析框架，还会自动带上那个岗位常用的数据源。

天机内置了四位分析师。

---

## 🔍 选品分析师

**擅长**：跨境电商产品机会挖掘、竞争格局与趋势分析

**自动带上**：Sorftime

**它的分析框架（四步法）**：

| 步骤 | 看什么 |
|---|---|
| 1. 需求验证 | 搜索量趋势、季节性、市场规模 |
| 2. 竞争格局 | 头部品牌集中度、Review 门槛、差异化空间 |
| 3. 趋势判断 | 近 90 天增长率、新品占比、社媒热度 |
| 4. 可行性评估 | 备货周期、利润空间、供应链复杂度 |

**行为特点**：先取数再下结论，不做没有依据的猜测，给的是具体可执行的选品建议而不是泛泛而谈。

**适合问**：
```
这个细分市场值不值得进
帮我评估一下宠物智能饮水机这个方向
这个类目新品还有没有机会
```

## 📊 广告分析师

**擅长**：Amazon 广告结构诊断、流量趋势分析、竞品广告复盘

**自动带上**：SIF 广告透视仪

**它的分析框架（三域法）**：

| 域 | 看什么 |
|---|---|
| 流量结果域 | 销量与流量的数量变化 |
| 市场竞争域 | 关键词排名与竞争格局变化 |
| 投放结构域 | 广告结构、预算与 ACoS 变化 |

**诊断原则**：

- 每个结论都要有机制性证据，不接受「可能是竞争加剧了」这类模糊表述
- 先确认到底是**流量问题、排名问题还是转化问题**，再往下钻
- 三个域看完综合，最后给可落地的优化动作

**默认站点**：美国站（你没指定时）

**适合问**：
```
这个 ASIN 最近广告花得多但没出单，帮我诊断一下
广告结构有什么问题
上个月流量掉了 30%，是什么原因
```

## 📈 数据分析师

**擅长**：业务数据库查询、数据洞察与可视化建议

**自动带上**：你配置的数据库连接（见[数据库连接](./database.md)）

**工作方式**：

- 查询前先摸清表结构，不瞎猜字段名
- 写可读性强的 SQL 并说明意图
- 结果用表格或要点呈现，并附上业务解读
- 发现异常数据会主动提示

**安全约束**：默认只做查询（读），不动你的数据。确实要写入时会先把 SQL 摆出来让你确认。

**适合问**：
```
帮我看看这个月各店铺的销售分布
把退货率最高的 10 个 SKU 列出来
对比一下上月和本月的转化情况
```

## 🔑 关键词研究员

**擅长**：Amazon 关键词挖掘、流量评估与竞品反查

**自动带上**：卖家精灵

**研究维度**：

| 维度 | 具体看 |
|---|---|
| 流量潜力 | 月搜索量、搜索趋势、季节性波动 |
| 竞争强度 | 头部 ASIN 占比、广告竞争度、PPC 出价参考 |
| 机会评估 | 搜索量高、竞争中低的「甜蜜点」词 |
| 竞品反查 | 从竞品 ASIN 反向挖它的核心流量词 |

**输出习惯**：先给词表（搜索量 / 竞争度 / 推荐指数），再附分析说明。

**适合问**：
```
帮我挖一批 phone stand 的长尾词
这个竞品 ASIN 的核心流量词是什么
哪些词是搜索量还行但竞争不激烈的
```

## 怎么开启技能

两种方式，效果一样：

**方式一：直接说。** 在对话里说「用选品分析师帮我看看这个品类」，助手会自动切过去，并在对话里提示已激活。

**方式二：去技能市场。** 左侧「技能市场」页可以浏览全部技能、查看各自的说明，从这里安装或启用。

## 技能会自动带上数据源

这是技能最省事的地方：开了广告分析师，它会自动激活 SIF 广告透视仪，你不用再单独 `@` 一次。前提是**你已经配好了那个连接器的密钥**——技能能自动激活，但没法替你填密钥。

## 不开技能行不行

行。不开技能时助手也能取数、也能分析，只是没有那套专业框架，回答会更通用一些。

**建议**：随口查个数不用开技能；要做一次正经的选品评估或广告诊断，开上对应技能，产出的结构化程度差别很明显。
