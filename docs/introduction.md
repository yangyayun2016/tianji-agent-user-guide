# 产品介绍

## 天机智能体是什么

天机智能体是一个面向跨境电商的 AI 助手。它跟普通聊天机器人的区别在于：它**能连上你的数据源**。

普通 AI 只能凭训练时学到的知识回答，问它「我这个 ASIN 上周广告花了多少钱」，它答不上来。天机可以——因为你把 SIF、领星 ERP 这些平台的密钥配进来之后，它会真的去调接口取数，再基于取回来的真实数据回答。

一句话概括：**你在用的那些跨境数据平台，天机帮你在一个对话框里统一问。**

## 适合谁

| 角色 | 典型用法 |
|---|---|
| **选品 / 产品经理** | 一个品类值不值得进、竞品格局怎么样、趋势在涨还是在跌 |
| **广告优化师** | 广告结构诊断、Campaign 贡献拆解、关键词坑位监控 |
| **运营** | 关键词研究、Listing 流量结构、竞品评论洞察 |
| **店铺负责人 / 老板** | 每天早上一份自动生成的销售与广告日报 |
| **团队管理者** | 把团队的运营 SOP 传进知识库，让新人问助手而不是问你 |

## 它是怎么工作的

从你的角度看只有三步：

1. **配一次密钥** — 在「连接器」页面把你已有的平台账号密钥填进去，一个平台配一次，以后一直有效。
2. **提问** — 在对话框里用大白话问，比如「帮我看看 B0C8M8JVMC 最近 30 天的 BSR 走势」。
3. **看结论** — 助手会先展示它调用了哪些数据源、取到了什么，再给出分析结论。需要的话，一键生成排版好的报告。

你不需要知道它调了哪个接口、传了什么参数。工具选择是助手自己判断的，你只要把问题说清楚。

## 主要功能一览

| 功能 | 在哪 | 一句话说明 |
|---|---|---|
| 智能对话 | 左侧「智能对话」 | 主入口，所有分析都从这里开始 |
| 技能市场 | 左侧「技能市场」 | 四个内置分析师，切换助手的专业人格 |
| 连接器 | 左侧「连接器」 | 配置各数据平台的密钥 |
| 知识库 | 左侧「知识库」 | 上传自有资料，让助手基于它回答 |
| 定时任务 | 左侧「定时任务」 | 设定周期任务，到点自动跑 |
| 消息渠道 | 左侧「渠道」 | 接飞书机器人，把结果推到群里 |
| 积分中心 | 右上角头像 →「积分中心」 | 余额、消耗流水、邀请好友 |
| 个人资料 | 右上角头像 →「个人资料」 | 用户名、注册信息、使用统计 |

> 左侧还有「资产库」和「项目」两个入口，目前是功能预览，尚未正式启用。

## 跟通用 AI 助手的区别

| | 通用 AI 助手 | 天机智能体 |
|---|---|---|
| 数据来源 | 训练语料 + 联网搜索 | 你自己账号下的真实平台数据 |
| 跨境场景 | 通用知识 | 内置选品/广告/关键词的专业分析框架 |
| 数据时效 | 取决于搜索结果 | 实时调接口，取当下的数 |
| 结论依据 | 通常无法核对 | 每一步取数过程都在对话里可见 |
| 私有资料 | 无 | 可上传知识库、可连自己的数据库 |
