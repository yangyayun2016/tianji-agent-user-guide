# 知识库

知识库让助手能读你自己的资料。运营 SOP、产品手册、竞品报告、历史复盘——传进来之后，助手回答时会先去里面检索相关内容，再结合数据给结论。

## 什么时候用知识库

| 场景 | 用什么 |
|---|---|
| 这次问完就不用了的一份表格 | 对话里直接上传附件 |
| 反复要查的运营规范、产品资料 | 知识库 |
| 团队共用的话术、流程、标准 | 知识库 |

一句话：**一次性资料用附件，长期资料建知识库。**

## 创建知识库

1. 左侧点「知识库」
2. 右上角「创建知识库」
3. 填名称（例如「产品目录」）和描述（说清里面装的是什么内容）
4. 点「创建」

建议按主题分开建，不要把所有东西堆进一个库。库分得清楚，检索才准。

## 上传文档

进入某个知识库，点上传，支持这些格式：

`PDF` `Word (.docx)` `Excel (.xlsx / .xls)` `TXT` `CSV` `Markdown` `JSON`

也支持上传 `.zip` 压缩包批量导入。

上传后文档会进入处理状态，系统解析文本、切成片段并建立索引。文档列表里能看到每份文档的状态：

| 状态 | 含义 |
|---|---|
| 处理中 | 正在解析和索引，稍等 |
| 完成 | 已可被检索 |
| 警告 | 部分内容没能提取，但可用 |
| 失败 | 解析失败，鼠标悬停可看原因 |

处理完成后，在「片段」标签页能看到文档被切成了哪些片段——这就是助手实际检索的单位。

### 上传失败怎么办

- **扫描版 PDF**：里面是图片不是文字，提取不到内容。需要先做 OCR 转成文字版再传。
- **加密文档**：先解除密码保护。
- **超长文档**：单份文档会截取前一部分内容做索引。太长的资料建议按章节拆成几份传。
- **空白结果**：确认文档里确实有可选中的文字，而不是纯图片或纯图表。

## 在对话中使用

跟连接器一样，在输入框里 `@` 选中知识库名称：

```
@产品目录 我们家这款饮水机的滤芯更换周期是多久
```

也可以直接说「查一下我们的产品目录，看看……」，助手会自己激活。

助手会在库里检索最相关的几个片段，把它们当作依据来回答。工具调用卡片里能看到它检索到了哪些片段——这是核对答案来源的地方。

## 知识库和连接器一起用

这是最有价值的组合。比如：

```
@FlyFus API @运营SOP 帮我按我们的 Listing 优化规范，
看看 B0XXXXXXXX 这个商品的标题和五点描述还有什么问题
```

助手会一边取商品的真实数据，一边对照你的内部规范，给出符合你团队标准的建议——而不是一套通用的网上说法。

## 管理

- **删除文档**：在文档列表里逐份删除，删除后相关片段一并失效
- **删除知识库**：整库删除，里面的文档和片段全部清除，不可恢复
- **搜索知识库**：库多了之后，用列表上方的搜索框按名称找

## 使用建议

**描述写清楚。** 知识库的描述会影响助手判断该不该来这里查。写「产品目录」不如写「我们在售全部 SKU 的规格参数、包装尺寸与滤芯更换周期」。

**一个主题一个库。** 把 SOP、产品资料、竞品报告混在一起，检索时容易串味。

**资料要更新。** 知识库里的内容不会自己变。规范改了、产品换代了，记得重新传一份并删掉旧的。
