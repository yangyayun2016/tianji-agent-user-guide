# 智能对话

对话页是天机的主入口。选品、广告、关键词、店铺数据，所有分析都从这里开始。

## 界面构成

| 区域 | 内容 |
|---|---|
| 左栏 | 历史对话列表，可搜索、可点击回到任意一轮旧对话 |
| 顶部 | 当前对话标题、「对话文档」面板、「分享对话」按钮 |
| 中间 | 消息流：你的提问、助手的思考过程、工具调用卡片、正文回答 |
| 底部 | 输入框、模型下拉、附件按钮，以及当前模型单价与积分余额 |

## 提问

直接用大白话提问即可。要用到某个数据源时，先在输入框里 `@` 选中对应的连接器。

```
@FlyFus API B0C8M8JVMC 近 90 天的 BSR 走势
```

**中文输入法友好**：用拼音打字时按回车确认候选词不会误发送，只有真正按回车才发送。

## 一次回答里会看到什么

### 1. 思考过程

如果你选的模型支持（DeepSeek V4 Pro、GPT-OSS 120B、Claude Opus 4.8），正文之前会有一段「思考中…」区块，写明它打算怎么查、怎么算。正文开始时会自动折叠，想看随时点开。

### 2. 工具调用卡片

助手每次去取数，都会插入一张折叠卡片：调用中显示「正在调用工具」，完成后变成结果预览。**点开可以看到取回来的原始数据。** 这是核对结论的最快方式。

### 3. 正文回答

基于取回来的数据写出的分析结论，Markdown 排版，表格、代码块、列表都能正常显示。

### 4. 生成报告按钮

每轮回答完成后，下方会出现「生成报告分析」按钮。详见[报告与定时任务](./reports-and-schedule.md)。

## 上传附件

点输入框旁的附件按钮，可以上传：

- **文档**：PDF、Word（.docx）、Excel（.xls/.xlsx）、CSV、TXT、Markdown、JSON、XML、HTML
- **图片**：PNG、JPG、GIF、WebP —— 需要选支持看图的模型（Claude Opus 4.8）
- **代码文件**：.py、.ts、.js
- **视频**：MP4、WebM

上传后助手会读取内容并结合你的问题分析。适合让它读一份竞品报告、一张后台截图，或一份导出的表格。

> 一次性资料用附件；要反复查的资料放[知识库](./knowledge-base.md)更合适。

## 断了不丢

这是天机跟一般聊天工具很不一样的一点：**回答生成中途，你可以关掉页面。**

刷新、切到别的页面、网络抖一下、手机切到后台——回答都在后台继续生成。你回来时它会从断掉的地方接着显示，思考过程和工具调用轨迹也一并还原，不用重新提问，也不会重复扣积分。

## 导出与分享

### 导出表格

助手取回的数据如果是表格形态，结果卡片上会有导出按钮，一键存成 Excel。

### 分享对话

点顶部「分享对话」，会生成一条公开链接。拿到链接的人不用登录就能看到这段对话的完整内容——适合把分析结论直接发给同事或客户。

> 链接是公开的，任何拿到的人都能看。含敏感数据的对话请谨慎分享。

### 对话文档

顶部的「对话文档」面板汇总了这段对话生成过的所有报告，点开可以直接跳转查看。

## 历史对话

左栏保存全部历史对话，标题由第一条提问自动生成。搜索框可按标题检索。点任意一条即可回到那段对话继续问，上下文完整保留。

## 上下文限制

单段对话最多 20 轮提问。达到上限后输入框会被禁用，并提示开启新对话。

这不是缺陷而是刻意的限制：对话越长，模型越容易被前面无关的内容干扰，回答质量反而下降。换个话题时，新开一段对话往往比接着问更准。

## 提问技巧

**给全三要素**：查什么、哪个站点、哪段时间。

**一次问一件事。** 复合问题拆开问，每一问的答案都更扎实。

**结论存疑先展开工具卡片**，看原始数据比反复追问快。

**分析类问题上强模型。** 简单查数用 DeepSeek V4 Flash 就够；要它做判断、给建议时，切到 Claude Opus 4.8 差别很明显。

**换话题就新开对话。** 上一个话题的上下文对新问题只有干扰。
