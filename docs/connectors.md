# 连接器

连接器是天机的核心。配好一个连接器，就等于把那个平台的数据接进了对话框。

目前已上线 7 个连接器，覆盖广告、选品、关键词、坑位监控和 ERP。

---

## 通用流程

### 一、配置（每个平台只需一次）

1. 左侧导航点「连接器」
2. 找到目标平台的卡片，点「配置」
3. 填入该平台的 Key / Secret（去哪拿见下面各节）
4. 点「**验证连接**」——这一步会真的去访问那个平台，验证通过说明密钥有效
5. 点「保存」

> 验证失败最常见的原因是密钥填错、复制时带了空格，或者该平台的密钥已过期。先回原平台确认密钥还有效。

### 二、在对话中使用

在对话输入框里输入 `@`，选中连接器名称，然后正常提问：

```
@卖家精灵 分析 iphone case 这个关键词的竞争情况
```

激活之后，这轮对话里助手随时可以调用该平台的数据。

**你不需要指定用哪个功能。** 助手会根据你的问题自己判断该取什么数。你只要把问题说清楚——哪个 ASIN、哪个站点、哪段时间。

### 三、看它取了什么

每次取数都会在对话里显示一张折叠卡片：先是「正在调用工具」，完成后变成结果预览。点开能看到取回来的原始数据。结论对不对，展开核一下就知道。

## 已上线连接器

### SIF 广告透视仪

**需要填**：Secret Key

**去哪拿**：登录 [sif.com](https://www.sif.com) → 账户设置 → API 密钥

**能问什么**：广告结构与流量分析。ASIN 有哪些 Campaign、各自贡献多少流量、广告结构最近有什么变动、流量异常的原因下钻到关键词级别。

**示例提问**：
```
@SIF 广告透视仪 B0XXXXXXXX 的广告结构是什么样的
@SIF 广告透视仪 这个 ASIN 最近 30 天流量掉了，帮我看看是哪个 Campaign 的问题
@SIF 广告透视仪 帮我拆一下这个广告组的关键词贡献
```

### 卖家精灵

**需要填**：Secret Key

**去哪拿**：登录卖家精灵官网 → 个人中心 → API 设置

**能问什么**：选品研究、ABA 分析、市场趋势、竞品追踪、关键词挖掘、流量来源。

**示例提问**：
```
@卖家精灵 分析 iphone case 这个关键词的竞争情况
@卖家精灵 帮我挖一批 phone stand 相关的长尾词
@卖家精灵 这个类目最近三个月的市场趋势怎么样
```

### Sorftime

**需要填**：Account SK

**去哪拿**：登录 Sorftime → 账户中心 → Account-SK

**能问什么**：选品分析与市场趋势、产品研究、竞争情报、趋势预测。

**示例提问**：
```
@Sorftime 帮我评估一下宠物饮水机这个细分市场值不值得进
@Sorftime 这个类目的头部集中度如何，新品还有机会吗
```

### FlyFus MCP

**需要填**：API Key（形如 `ak_mcp_live_...`）

**去哪拿**：登录 FlyFus → 开放平台 → 创建应用

**填写注意**：只填原始 Key，**不要**自己加 `Bearer ` 前缀，系统会自动处理。

**能问什么**：商品数据分析、关键词引擎、市场数据引擎、AI 推荐与 Rufus 流量洞察。

---

### SIF 坑位监控

**需要填**：API Key（与 SIF 广告透视仪同一个）

**去哪拿**：登录 [sif.com](https://www.sif.com) → 账户设置 → API 密钥

**能问什么**：某个关键词在指定小时的搜索页坑位快照——自然位、SP 广告位、推荐位、SB/SBV 各自被谁占着，含 ASIN 排名、价格、评分。默认查美国站。

提问时**必须说清关键词和具体到小时的时间点**，例如「2026-06-10 14:00」。

**示例提问**：
```
@SIF 坑位监控 查一下 iphone case 在 2026-06-10 14:00 的坑位情况
@SIF 坑位监控 phone stand 昨天下午 3 点的自然位前十是哪些 ASIN
```

### 领星 ERP

**需要填**：App ID + App Secret

**去哪拿**：登录领星 ERP → 设置 → 开放接口 → 创建应用

**能问什么**：三类数据——

| 能查 | 说明 | 提问时要给 |
|---|---|---|
| 订单 | 订单号、ASIN、SKU、销量、金额、状态 | 起止日期 |
| 库存 | 在库数量、可售库存、库龄 | 可按品牌或 SKU 筛，也可全量 |
| 销售报表 | 销售额、销量、退货率等指标 | 起止日期 |

**示例提问**：
```
@领星 ERP 查询上周的销售数据
@领星 ERP 帮我看看 6 月 1 号到 6 月 15 号的订单情况
@领星 ERP 这个品牌现在还有多少可售库存，库龄多久了
```

### FlyFus API

**需要填**：API Key（与 FlyFus MCP 共用同一个 Key，不用另外申请）

**填写注意**：只填原始 Key，不要加 `Bearer ` 前缀。

**能问什么**：这是功能最全的连接器，分三块——

**商品**
- 商品详情：标题、品牌、价格、BSR、评分、评论数、类目树、上架时间
- 历史趋势：价格 / BSR / 评分 / 评论数的历史曲线，可按日、周、月
- 评论：分页拉评论，可按星级和时间筛
- 评论洞察：AI 提炼买家痛点、产品优势、使用场景（仅美国站）
- 商品检索：按价格、评论数、上架时间、关键词多条件筛品
- 关键词反查：某个 ASIN 的流量来源词及 ABA 排名

**关键词**
- 关键词详情：ABA 搜索量、点击/转化集中度、Top3 点击与转化共享
- ABA 历史：周报 / 月报的搜索量历史趋势
- 关键词批量检索：按 ABA 排名、点击共享等条件批量筛词
- 搜索结果：亚马逊搜索页近 30 天的实时结果，含自然位与广告位

**类目**
- BSR 类目树：查类目结构，可逐级展开子类目

**示例提问**：
```
@FlyFus API 帮我查一下 B0C8M8JVMC 这个商品的详细信息
@FlyFus API iphone case 这个关键词的 ABA 搜索量趋势是什么样的
@FlyFus API 帮我找一下价格在 20-50 美元、评论数 500 以上的 phone stand 商品
@FlyFus API B0C8M8JVMC 的流量词有哪些，只要 ABA 排名 10000 以内的
@FlyFus API 看一下这个 ASIN 近半年的 BSR 和价格走势
@FlyFus API 这个商品的差评里买家主要在抱怨什么
```

## 提问技巧

**说清三件事**：查什么（ASIN / 关键词 / 品牌）、哪个站点、哪段时间。信息给全，助手一轮就能取到；给不全它会反问你，多耗一轮。

**一次问一件事。** 「帮我分析这个 ASIN 的广告、库存和竞品」这种复合问题，不如拆成三问来得准。

**追问不用重复背景。** 同一轮对话里助手记得上文，接着问「那它上个月呢」就行。

**结论存疑就展开卡片。** 取回来的原始数据都在里面，比反复追问快。

## 常见问题

**配置保存成功，但对话里说用不了？**
检查有没有在输入框里 `@` 选中这个连接器。只保存配置不激活，助手是看不到它的。

**验证连接一直失败？**
先确认密钥在原平台还有效；再检查复制时有没有带上首尾空格；FlyFus 系列注意不要自己加 `Bearer ` 前缀。

**助手说「正在检索」就停住了？**
重新提问一次。如果反复出现，换一个更强的模型试试。

**能同时用两个连接器吗？**
可以。对话过程中助手需要另一个数据源时会自己激活，你也可以在提问时 `@` 多个。
